NCV CONVENTION HALL — CONCEPT WEBSITE DEMO

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted NCV-Convention-Hall-Demo folder in Visual Studio Code.
3. Right-click index.html and choose Open with Live Server.
4. Use the navigation to check Home, Our venue, Facilities, Gallery and Contact.

PROJECT FILES
- index.html       Homepage
- about.html       Venue information
- facilities.html  Amenities
- gallery.html     Photo gallery with lightbox
- contact.html     Contact details and WhatsApp enquiry form
- style.css        Shared responsive design
- script.js        Navigation, gallery and enquiry form functionality
- images/          Local image fallback graphic

IMPORTANT VERIFICATION NOTES
- Capacity, room count, parking count and facilities are taken from third-party venue directory listings. Confirm them with the venue before publishing.
- The WhatsApp button uses the public business listing phone number. WhatsApp registration for that number was not independently confirmed. Test the number with the owner before deployment.
- The venue photographs are displayed from the public NCV album on Mandap.com. The image host is external and the photos contain Mandap branding/watermarks. Image rights remain with the respective owner/platform. Ask NCV for original, approved photographs for the production website. Each photograph has a local SVG fallback so a failed external image request does not show a broken-image icon.
- The enquiry form opens a pre-filled WhatsApp message. It does not save enquiries to a database or create a booking.
- This is a concept demo, not a final factual representation or booking system.
